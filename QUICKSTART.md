# Быстрый старт без опыта программирования

Роутер запускается **на вашем компьютере** и соединяет чат-клиент с моделями Polza. Сервер в облаке, Docker и Git не нужны. Окно терминала придётся оставить открытым, пока вы пользуетесь роутером.

> **Важно:** скачивание, запуск и локальная проверка бесплатны. Сообщения моделям расходуют баланс Polza: основная модель, Jev, а для картинки — ещё её предварительный анализ. Автоматической подписки на бесплатное использование нет. Данные уходят внешним провайдерам. Это экспериментальный локальный проект, не защищённый публичный сервер.

## 1. Подготовьте Python

Нужен **Python 3.10 или новее**. Проверено CI на 3.10 и 3.12; для начала рекомендуем 3.12.

- **Windows:** откройте PowerShell (найдите его через меню «Пуск») и введите `py -3 --version`.
- **macOS/Linux:** откройте приложение «Терминал» и введите `python3 --version`.

Если Python не найден или версия ниже 3.10:
- Windows/macOS: установите подходящую версию с [python.org/downloads](https://www.python.org/downloads/). На Windows в установщике включите добавление Python в PATH, если такой пункт предлагается. Затем заново откройте терминал.
- Linux: установите Python через менеджер пакетов вашего дистрибутива или попросите помочь с установкой. Название команды зависит от системы.

**Никаких `pip install` для этого проекта не требуется.**

## 2. Скачайте и распакуйте проект

1. Откройте [страницу проекта](https://github.com/uprosti-tech/uprosti-vibe).
2. Нажмите **Code → Download ZIP** — так скачивается текущая версия инструкции и кода из `main`.
3. Распакуйте архив в удобную папку, например в «Загрузки». Не запускайте файлы прямо внутри ZIP.
4. Найдите папку, в которой лежит **`jev_router.py`**. После распаковки она обычно называется `uprosti-vibe-main`.

Нужна именно зафиксированная версия? Исходники релиза доступны в [Releases](https://github.com/uprosti-tech/uprosti-vibe/releases), в пункте **Source code (zip)**; инструкция там может быть старее этой.

## 3. Откройте терминал в папке проекта

**Windows:** откройте папку с `jev_router.py` в Проводнике, щёлкните адресную строку, введите `powershell` и нажмите Enter. Откроется окно с нужной текущей папкой.

**macOS:** откройте «Терминал», введите `cd ` (с пробелом), перетащите папку с `jev_router.py` из Finder в окно терминала и нажмите Enter.

**Linux:** используйте «Открыть в терминале» в файловом менеджере или команду `cd` с путём к папке.

Проверка содержимого: на Windows введите `dir`, на macOS/Linux — `ls`. В списке должен быть `jev_router.py`.

## 4. Подготовьте ключ Polza

Войдите в свой аккаунт на [polza.ai](https://polza.ai) и создайте/скопируйте API-ключ в личном кабинете. Не путайте его с паролем аккаунта. Для реальных запросов нужен доступный баланс; перед пополнением проверьте актуальные тарифы и условия Polza.

**Не отправляйте ключ в чат, issue, скриншот или GitHub.** Ниже ключ вводится скрыто: он не появится в команде и не будет записан в историю команд. Он будет доступен запущенному процессу через окружение.

Файл `.env.example` — только пример настроек. **Создавать `.env` не нужно: роутер его автоматически не читает.**

## 5. Запустите роутер

Скопируйте **одну** команду для своей системы целиком и нажмите Enter.

### Windows — PowerShell

```powershell
py -3 -c "import getpass, os, runpy; os.environ['POLZA_API_KEY'] = getpass.getpass('Polza API key: ').strip(); runpy.run_path('jev_router.py', run_name='__main__')"
```

### macOS / Linux — Терминал

```bash
python3 -c "import getpass, os, runpy; os.environ['POLZA_API_KEY'] = getpass.getpass('Polza API key: ').strip(); runpy.run_path('jev_router.py', run_name='__main__')"
```

При приглашении `Polza API key:` вставьте ключ и нажмите Enter. **Символы при вводе не отображаются — это нормально.** На Windows обычно работает Ctrl+V, на macOS — Cmd+V, в Linux часто Ctrl+Shift+V. Если терминал предупреждает, что не может скрыть ввод, отмените Ctrl+C и используйте обычный системный терминал, не веб-консоль/IDE без TTY.

После запуска появится строка примерно такого вида:

```text
jev_router слушает http://127.0.0.1:8787 — в Goose выбирай модель auto
```

Это означает, что локальный сервер стартовал. **Правильность ключа и доступность моделей ещё не проверены.** Не закрывайте окно. Все следующие настройки делайте в другом окне или приложении.

## 6. Бесплатно проверьте локальное соединение

Откройте в браузере на том же компьютере:

**http://127.0.0.1:8787/v1/models**

Должен появиться JSON — текст со списком, где есть `"id": "auto"`. Это нормально: красивой веб-страницы у роутера нет.

Эта проверка **не обращается к Polza и не расходует баланс**. Она проверяет только локальный сервер, не API-ключ, интернет и возможность генерации. Если открыть просто `http://127.0.0.1:8787/`, ошибка `not found` ожидаема — используйте полный адрес `/v1/models`.

## 7. Подключите чат-клиент

Нужен клиент с поддержкой **пользовательского OpenAI-совместимого провайдера и Chat Completions**. Одной веб-страницы ChatGPT недостаточно. Названия полей зависят от программы, но итоговый адрес запроса должен быть именно таким:

```text
http://127.0.0.1:8787/v1/chat/completions
```

| Что спрашивает клиент | Значение |
|---|---|
| Тип API | OpenAI-compatible / Chat Completions (не Responses API) |
| Base URL, если клиент сам добавляет `/chat/completions` | `http://127.0.0.1:8787/v1` |
| Полный URL, если требуется полный адрес endpoint | `http://127.0.0.1:8787/v1/chat/completions` |
| Модель / Model ID | `auto` — маленькими латинскими буквами |
| API-ключ локального провайдера | Оставить пустым; если поле обязательно — `local` |

Настоящий ключ Polza вводится **при запуске роутера**, а не в настройках локального клиента. Прокси не проверяет клиентский ключ `local`: это не защита доступа.

Если клиент отдельно спрашивает **корневой URL и путь**, используйте корень `http://127.0.0.1:8787` и путь `v1/chat/completions`. Не добавляйте `/v1` дважды. Точные поля и способ включения изображений смотрите в документации своего клиента.

Готовая настройка для **OpenCode** — в отдельном файле [OPENCODE.md](OPENCODE.md):
одна команда `./setup_opencode.sh` записывает конфиг провайдера, остальное
подхватывается при перезапуске клиента.

Клиент в Docker, на сервере или телефоне **не находится на том же localhost**. Этот быстрый старт рассчитан на обычное приложение на том же компьютере. Не открывайте порт в интернет ради подключения: встроенной авторизации и TLS нет.

### Первое сообщение — уже платное

Только если готовы расходовать баланс, отправьте короткое сообщение, например «Ответь одним словом: привет». Запрос запускает маршрутизацию и генерацию. В терминале появится выбранная модель, а в клиенте — ответ.

Не запускайте `test_routing.py` или `python3 -m benchmark run` для бесплатной проверки связи — они тоже платные.

### Если нужны картинки

Клиент должен считать модель `auto` способной принимать изображения (vision) и действительно отправлять их. Если вместо картинки появляется `[image omitted: model does not support vision]`, это ограничение настроек клиента: **картинка удалена до отправки в роутер**. Одного выбора `auto` недостаточно. Возможность и способ указания vision зависят от клиента и его версии.

Оригинал изображения получает основная модель, а для Jev вызывается отдельный анализатор. Это дополнительные расходы и передача данных внешним провайдерам.

## 8. Остановка и следующий запуск

Чтобы остановить сервер, вернитесь в его терминал и нажмите **Ctrl+C**. Сообщение `KeyboardInterrupt` при остановке допустимо.

После перезагрузки компьютера или закрытия окна откройте папку проекта и повторите шаг 5. Ключ придётся ввести заново. Этот способ не сохраняет его в файл; автозапуска пока нет.

## Если не заработало

| Сообщение / симптом | Что проверить |
|---|---|
| `python3` / `py` не найден | Python установлен? Перезапустите терминал после установки и повторите проверку версии. |
| `can't open file`, `No such file`, `FileNotFoundError` для `jev_router.py` | Терминал открыт не в той папке. Повторите шаг 3; файл должен быть виден в `dir` / `ls`. |
| Подсказка `Задай ключ...` | Ключ пустой или не передан. Повторите команду шага 5 и введите ключ. |
| `Address already in use`, `WinError 10048` | Порт 8787 занят. Возможно, роутер уже запущен: сначала проверьте `/v1/models`. Старый экземпляр можно остановить Ctrl+C в его окне. Не завершайте незнакомые процессы наугад. |
| Браузер не открывает `/v1/models` | Процесс работает? Адрес начинается с `http`, а не `https`? Браузер на том же компьютере? |
| Браузер показывает `not found` | Используйте полный адрес `http://127.0.0.1:8787/v1/models`, а не корень. |
| Клиент сообщает `connection refused` | Сервер остановлен или URL/порт неверны; сначала повторите бесплатный шаг 6. |
| Ошибка 401/403 от Polza | Проверьте ключ и права доступа в кабинете; локальный тест не проверяет ключ. |
| Ошибка о балансе, 402 или 429 | Проверьте текст ошибки, баланс и ограничения провайдера; 429 также может означать ограничение частоты. Не повторяйте платные запросы бесконечно. |
| Модель недоступна, 404/5xx | Проверьте актуальную доступность у Polza и URL в клиенте. В коде зафиксированы конкретные model ID; они могут меняться. Fallback помогает не во всех случаях. |
| `image omitted` | Настройте vision для `auto` в клиенте; сервер не восстановит удалённую картинку. |

Если нужна помощь, укажите ОС, версию Python и клиента, шаг инструкции и текст ошибки **без ключей, приватных сообщений и документов**. Логи роутера могут содержать часть запроса и ответ ошибки upstream — проверьте их перед публикацией.
