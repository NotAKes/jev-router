# Кандидат первого публичного релиза

Рекомендуемое обозначение: `v0.1.0` — экспериментальный локальный роутер,
не production API-сервис и не обученная собственная модель.

## До публикации

- [x] Воспроизводимые синтетические данные и проверяемые эталоны.
- [x] Strict и normalized метрики разделены, протокол фиксируется в manifest.
- [x] Офлайн-тесты и CI без ключей/платных вызовов.
- [x] CONTRIBUTING, SECURITY, шаблон окружения.
- [x] Заполнить итоговый отчёт extended-dev и единственного финального test.
- [x] Сверить ограничения и выводы отчётов: не скрывать проигрыш cheap baseline.
- [x] Проверить подготовленные файлы и историю Git на секреты (эвристический скан не гарантия).
- [ ] Выбрать лицензию с владельцем. Без LICENSE публичный код не является нормально лицензированным open source.
- [ ] Подтвердить изменение видимости репозитория PRIVATE → PUBLIC с владельцем.
- [ ] Запустить CI в GitHub и проверить обе версии Python (локальный прогон одной версии недостаточен).
- [ ] После проверки создать тег и GitHub Release; не называть черновик опубликованным релизом.

## Границы публикации

Не публиковать `benchmark/runs/`, локальные конфиги, API-ключи, личные инструкции,
пользовательские сессии, содержимое окружения и локальные пути владельца.
Агрегаты результатов можно публиковать после проверки; все задачи синтетические.
Новые платные прогоны не являются автоматической частью выпуска.
