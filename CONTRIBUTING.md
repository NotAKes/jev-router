# Участие в разработке

Нужен Python 3.10 или 3.12. Офлайн-проверки используют только стандартную
библиотеку: установка зависимостей и API-ключи не нужны.

## Проверки перед PR

Из корня репозитория:

```sh
export PYTHONDONTWRITEBYTECODE=1
python3 -m unittest -v test_jev_router test_benchmark test_benchmark_scoring test_benchmark_extended
python3 -m benchmark.extended --check
python3 -m benchmark plan
```

Запускайте тесты явным списком, а не через `unittest discover`: платный
`test_routing` намеренно исключён, хотя его импорт сейчас безопасен.
`benchmark plan` строит план офлайн и не запускает платную оценку.

## Безопасность и данные

- CI выполняет только офлайн-проверки, без вызовов API, секретов и платных
  прогонов. Используются Python 3.10 и 3.12 без установки зависимостей.
- Платные интеграционные проверки запускаются отдельно, вручную, только после
  явного согласования расходов; они не входят в команды выше или в CI.
- Не добавляйте ключи, `.env`, приватные данные, логи API и артефакты прогонов
  в коммиты или вложения к PR. Не выводите секреты в логи; CI не загружает артефакты.
- Для тестов используйте синтетические датасеты без персональных данных.
- Не редактируйте holdout после оценки и не подгоняйте его под результаты.
  Изменения датасетов и разделения выборок описывайте в PR до новой оценки.

В PR кратко опишите изменения и результаты проверок. Код и оригинальные
данные репозитория распространяются по MIT; не добавляйте материалы с несовместимыми правами.
