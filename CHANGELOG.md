# Changelog

## v0.1.0 — 2026-11-15

### Добавлено

- Описание изображений перед Jev с передачей оригиналов основной модели.
- Ограниченный RAM-кеш описаний, vision-совместимые уровни, fallback и обработка image-only.
- Офлайн-тесты HTTP, кеша, обработки ошибок, планировщика и оценки.
- Небольшой synthetic dev/test и воспроизводимый extended-dev с проверяемыми эталонами.
- Opt-in платный benchmark с планированием расходов, журналом перед отправкой, сохранением ответов, strict/normalized метриками и анализом по задачам.
- Явное безопасное продолжение полностью учтённого прогона без повторной оплаты готовых ячеек; неизвестные/ошибочные запросы не повторяются автоматически.
- CI на Python 3.10/3.12 без API-ключей, SECURITY и CONTRIBUTING.

### Уточнено

- Jev тарифицируется по входным токенам; при наличии `usage.cost_rub` приоритет имеет сообщённая API стоимость.
- Локальный прогноз не является пределом списаний у провайдера.
- Бенчмарк оценивает single-turn ответы без инструментов; он не подтверждает качество долгих агентных задач.
- Проект — экспериментальная LLM-инфраструктура, не собственная обученная модель.
