# Changelog

## Unreleased

- Добавлен Windows-комплект Jev для OpenCode: запуск без уровней Anthropic, настройка провайдера, инструкция и воспроизводимая сборка ZIP.
- Закрепление уровня теперь требует уникального `X-Jev-Session-ID`: совпадающие первые сообщения больше не связывают независимые чаты.
- Роутер отклоняет некорректные аргументы и порт при старте, не повторяет генерацию на другой модели после `401`, `402` или `403` и не пишет текст сообщений в журнал маршрутизации.

### Исправлено

- 400 `The encrypted content for item rs_... could not be verified`: reasoning из истории клиента (`reasoning_details`, `reasoning_opaque`, `reasoning_content`, части `reasoning*` с `rs_`-id) вырезается перед отправкой. Зашифрованный блок привязан к модели и эндпоинту, которые его выдали, поэтому после смены модели под тем же уровнем запрос падал на каждом ходе. Отключается `JEV_KEEP_REASONING=1`.

### Добавлено

- `OPENCODE.md` и `setup_opencode.sh`: установка OpenCode, настройка провайдера `jev/auto` одной командой, разбор ошибки про encrypted content.
- Уровни `mini`, `flash`, `sol-pro`, `astra`, `astra-pro`; отключение уровней через `--disable a,b` и `JEV_DISABLE_TIERS`.
- Кеш префикса Anthropic: два breakpoint'а — системный промпт и последнее сообщение с содержимым.

- Пошаговый QUICKSTART без Git для Windows/macOS/Linux: скрытый ввод ключа, бесплатная локальная проверка, подключение клиента и диагностика ошибок. Код роутера не менялся.

## v0.1.0 — 2026-11-15

### Добавлено

- Описание изображений перед Jev с передачей оригиналов основной модели.
- Ограниченный RAM-кеш описаний, vision-совместимые уровни, fallback и обработка image-only.
- Офлайн-тесты HTTP, кеша, обработки ошибок, планировщика и оценки.
- Небольшой synthetic dev/test и воспроизводимый extended-dev с проверяемыми эталонами.
- Opt-in платный benchmark с планированием расходов, журналом перед отправкой, сохранением ответов, strict/normalized метриками и анализом по задачам.
- Явное безопасное продолжение полностью учтённого прогона без повторной оплаты готовых ячеек; неизвестные/ошибочные запросы не повторяются автоматически.
- CI на Python 3.10/3.12 без API-ключей, SECURITY и CONTRIBUTING.

### Уточнено

- Jev тарифицируется по входным токенам; при наличии `usage.cost_rub` приоритет имеет сообщённая API стоимость.
- Локальный прогноз не является пределом списаний у провайдера.
- Бенчмарк оценивает single-turn ответы без инструментов; он не подтверждает качество долгих агентных задач.
- Проект — экспериментальная LLM-инфраструктура, не собственная обученная модель.
