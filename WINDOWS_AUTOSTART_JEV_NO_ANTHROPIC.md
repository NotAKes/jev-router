# Автозапуск Jev без Anthropic на Windows

## Что это
Батник [1] запускает локальный роутер Jev [2] и исключает уровни Anthropic [3] из автоматического выбора `auto`:
- `haiku`
- `sonnet`
- `opus`

В `auto` останутся только уровни других поставщиков. Это не запрет на Anthropic во всём OpenCode: если выбрать другой провайдер или обратиться к Jev с явным ID модели вместо `auto`, правило не применяется.

## Что сделать

### 1) Распакуй архив
Распакуй весь ZIP в постоянную папку, например `Документы\Jev`. Не запускай файлы прямо из ZIP. `jev_router.py` и оба файла `.bat` должны лежать рядом.

Если обновляешь старую установку, закрой старое окно Jev, распакуй новую версию в отдельную папку и замени ярлык в автозагрузке. Если ключ раньше был только в батнике, настрой переменную среды по следующему шагу. Не пересылай старый батник с ключом.

### 2) Сохрани ключ Polza в настройках Windows
1. В поиске меню «Пуск» набери **Изменение переменных среды для текущего пользователя** и открой найденное окно.
2. В верхней части окна («Переменные среды пользователя») нажми **Создать**. Если такая переменная уже есть, выбери её и нажми **Изменить**.
3. В поле имени введи `POLZA_API_KEY`, а в поле значения вставь свой ключ Polza [4] из личного кабинета. Нажми **ОК** во всех открытых окнах.
4. Если батник всё ещё не видит ключ, выйди из Windows и войди снова.

Это переменная среды [19]. Ключ не нужно вставлять в батник или OpenCode. Не отправляй его другим и не показывай на скриншотах.

### 3) Установи Python, если его ещё нет
Если Python [5] уже установлен, этот шаг можно пропустить.

1. Открой сайт: [python.org/downloads](https://www.python.org/downloads/)
2. Скачай установщик Python для Windows с официального сайта и запусти его.
3. Если установщик предлагает `Add Python to PATH` [6] и установку `py launcher`, включи обе опции. Если скачался Python Install Manager, установи его, затем открой `cmd` и выполни `py install 3`.
4. После установки закрой и заново открой командную строку.

Проверка:

1. Нажми `Win + R`
2. Введи `cmd` [7], нажми Enter
3. Введи:

```bat
py -3 --version
```

Подходит Python **3.10 или новее**. Если команда не найдена, проверь, что установлен Python Install Manager или `py launcher`.

### 4) Запусти батник один раз вручную
Дважды кликни по `start_jev_no_anthropic.bat`.

Если всё нормально, появится окно и строка вроде:

```text
Jev Router listening on http://127.0.0.1:8787
```

Окно должно оставаться открытым, пока Jev нужен.

### 5) Добавь в автозагрузку [10]
Самый простой способ:

1. Нажми `Win + R`
2. Введи команду [8]:

```text
shell:startup
```

3. Откроется папка автозагрузки
4. В папке Jev нажми правой кнопкой на `start_jev_no_anthropic.bat` → «Копировать». В папке автозагрузки нажми правой кнопкой по пустому месту → «Вставить ярлык» [9] (на Windows 11 пункт может быть под «Показать дополнительные параметры»). Сам батник оставь рядом с `jev_router.py`.

После этого Jev будет запускаться сам при входе в Windows.

## Установи OpenCode Desktop и подключи Jev

1. Скачай OpenCode Desktop [11] для Windows с https://opencode.ai/desktop. Нужна версия V2. Для большинства компьютеров подходит **x64** [12], для компьютера на ARM — **ARM64**. Если сомневаешься, посмотри «Параметры → Система → О системе → Тип системы».
2. Запусти скачанный установщик и следуй подсказкам.
3. Дважды щёлкни `setup_opencode_jev.bat` и дождись `Jev Auto configured`. Батник подключит провайдера [13]. В новом файле настроек Jev станет моделью по умолчанию; в существующем файле прежний выбор сохранится. Ключ Polza в OpenCode вводить не нужно.
4. Открой OpenCode и в новом чате выбери **Jev Auto** [14] (`jev/auto`). Если приложение уже открыто и модель не появилась, выполни `/reload` [18] или перезапусти OpenCode.

Перед изменением существующего `opencode.json` [15] установщик создаёт свежую резервную копию `opencode.json.<случайный суффикс>.bak` рядом с ним. Если настройки уже правильные, файлы не меняются. При смене порта задай одну и ту же переменную `JEV_ROUTER_PORT` для запуска и настройки, затем запусти оба батника заново. Чтобы явно назначить Jev моделью по умолчанию в существующем конфиге, запусти `setup_opencode_jev.bat --default` из `cmd` в папке Jev.

### Если установщик нашёл JSONC или свою настройку Jev

Установщик ничего не меняет. Открой существующий файл настроек (обычно `%USERPROFILE%\.config\opencode\opencode.jsonc` или `opencode.json`; при заданном `XDG_CONFIG_HOME` — в его подпапке `opencode`). Сначала сделай копию файла. Внутрь существующего объекта `providers` добавь запись ниже, отделив её запятой от соседних записей. Если `providers` нет, создай один объект `"providers": { ... }` в корне. Если `jev` уже есть, не добавляй второй: проверь адрес и модель в существующей записи. Не заменяй весь конфиг этим фрагментом.

```jsonc
"jev": {
  "name": "Jev Router",
  "package": "@opencode/ai/providers/openai-compatible",
  "settings": { "baseURL": "http://127.0.0.1:8787/v1" },
  "models": {
    "auto": {
      "name": "Jev Auto",
      "capabilities": { "tools": true, "input": ["text", "image"], "output": ["text"] }
    }
  }
}
```

Если в окне Jev указан другой порт, подставь его в `baseURL`. Сохрани файл и перезагрузи настройки OpenCode.

## Как проверить
Открой адрес [17] из окна запуска, дописав `/v1/models`. Для стандартного порта:

```text
http://127.0.0.1:8787/v1/models
```

Если виден JSON [16] с моделью `auto`, локальный роутер отвечает. Эта проверка бесплатна и не проверяет ключ, баланс или доступность Polza. Отправка сообщения в Jev Auto — отдельная проверка генерации, она расходует баланс Polza.

## Как остановить
Закрой окно батника или нажми `Ctrl + C` в его окне.

## Если не запускается
- Проверь, что `jev_router.py` лежит рядом с батником.
- Проверь, что `POLZA_API_KEY` задана в переменных текущего пользователя. Если Windows ещё не подхватила её, выйди из системы и войди снова.
- Проверь, что Python установлен и команда `py -3 --version` работает.
- Если порт занят, возможно, Jev уже запущен через автозагрузку. Проверь `/v1/models`, прежде чем запускать второе окно.

## Словарик к сноскам

[1] **батник** — Файл .bat: Windows выполняет записанные в нём команды при двойном щелчке.

[2] **локальный роутер Jev** — Программа на твоём компьютере, которая выбирает модель и пересылает запрос в Polza.

[3] **Anthropic** — Компания, которая выпускает модели Claude: Haiku, Sonnet и Opus.

[4] **ключ Polza** — Секретный код из личного кабинета Polza. По нему сервис понимает, с чьего баланса оплачивать запросы.

[5] **Python** — Программа, которая запускает файлы .py. Она нужна для работы Jev.

[6] **Add Python to PATH** — Галочка, которая помогает Windows находить Python по имени команды.

[7] **cmd** — Командная строка Windows: окно, куда можно вводить команды.

[8] **shell:startup** — Команда, которая открывает папку автозагрузки текущего пользователя.

[9] **ярлык** — Ссылка на файл. В автозагрузку кладут ярлык, а сам батник оставляют рядом с Jev.

[10] **автозагрузку** — Запуск программы при входе в Windows без ручного открытия.

[11] **OpenCode Desktop** — Приложение с чатом для работы с моделями. Desktop означает, что оно устанавливается на компьютер.

[12] **x64** — Вариант установщика для большинства современных компьютеров на Intel и AMD. ARM64 — вариант для компьютеров с процессором ARM.

[13] **провайдер** — Настройка, которая указывает OpenCode, куда отправлять запросы. Здесь это Jev.

[14] **Jev Auto** — Пункт в списке моделей OpenCode. Это не отдельная нейросеть: Jev сам выбирает модель. jev/auto — имя этого пункта в настройках.

[15] **opencode.json** — Файл настроек OpenCode. .jsonc — похожий формат с комментариями, а .bak — резервная копия.

[16] **JSON** — Текст в формате, удобном для программ. Список моделей в браузере выглядит как текст — это нормально.

[17] **127.0.0.1:8787** — Адрес Jev на этом же компьютере. 8787 — номер порта, по которому OpenCode находит Jev.

[18] **/reload** — Команда OpenCode для повторной загрузки настроек.

[19] **переменная среды** — Именованная настройка Windows, которую Jev читает при запуске.
