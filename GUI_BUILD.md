# Jev Router GUI: запуск и сборка

`jev_gui.py` — экспериментальный интерфейс для Jev Router. Открытие окна **не запускает** роутер. Выберите уровни и нажмите «Запустить»: приложение запустит собственный процесс и после подтверждения его готовности автоматически добавит провайдера Jev в OpenCode. Автонастройку можно отключить в окне. При штатном закрытии приложения останавливается только запущенный им процесс.

В исходниках нужен Python 3.10+ с Tkinter:

```sh
python3 jev_gui.py
```

На Windows вместо `python3` можно использовать `py -3`. Понадобятся установленный OpenCode и ключ Polza. Ключ вводится в окно либо берётся из `POLZA_API_KEY` и **не сохраняется приложением**; при запуске из Finder переменная терминала может быть недоступна. Выбор уровней сохраняется в `~/.config/jev-router/gui.json` или в `$XDG_CONFIG_HOME/jev-router/gui.json`.

Чекбоксы ограничивают модели для автоматического выбора и запасные варианты, но не прямые запросы по ID модели. Для выбора маршрута используется `typesafe/jev`, а для изображений — дополнительная vision-модель. Запросы могут быть платными; бесплатная локальная проверка не подтверждает правильность ключа или наличие средств.

Автонастройка сохраняет другие настройки и при изменении существующего `opencode.json` создаёт резервную копию рядом с ним. Если уже была выбрана другая модель по умолчанию, она остаётся прежней: выберите `jev/auto` в OpenCode или явно включите в приложении опцию смены модели. При наличии `opencode.jsonc`, собственных настроек провайдера Jev или некорректного конфига приложение сообщит об ошибке, не перезаписывая конфигурацию. Настройки проекта или политики могут перекрывать глобальную настройку.

## Установка готового приложения

На странице релиза скачайте пакет своей платформы:

- **macOS Apple Silicon (M1 и новее):** `jev-router-gui-macos-arm64.zip`.
- **macOS Intel:** `jev-router-gui-macos-x86_64.zip`.
- **Windows x64:** `jev-router-gui-windows-x86_64.zip`.

На Mac распакуйте ZIP и перенесите `JevRouter.app` в «Программы». На Windows распакуйте **всю** папку `JevRouter` в постоянное место и запустите `JevRouter.exe`; папка `_internal` обязательна. Python отдельно не нужен. Эти ZIP — переносимые пакеты, а не MSI/DMG-установщики; автоматическая установка и ярлыки пока не предусмотрены.

Пакеты не подписаны сертификатами издателя и не нотариализованы Apple: возможны предупреждения SmartScreen/Gatekeeper. Не отключайте системную защиту. На странице релиза перечислены проведённые проверки; полноценная проверка на чистых компьютерах пока не проведена.

Кнопка «Проверить обновления» проверяет опубликованный стабильный релиз GitHub и наличие ZIP для вашей ОС/архитектуры. При наличии новой версии предложит открыть страницу релиза; скачивание и замена приложения выполняются вручную после закрытия старой версии. Это не `git pull` и не автоматическая установка. Ключи и настройки обновлятор не меняет.

## Автономная сборка

Готовые ZIP для macOS и Windows публикуются на [странице релизов](https://github.com/uprosti-tech/uprosti-vibe/releases), если сборки доступны. Это экспериментальные неподписанные пакеты: Windows-сборку и запуск в чистой системе необходимо проверять отдельно. Для собственной сборки команды ниже требуют PyInstaller и выполняются на соответствующей ОС и архитектуре.

PyInstaller `--onedir --windowed` включает Python и Tkinter, поэтому пользователю не нужна отдельная установка Python. На Windows распространяется **вся папка** приложения, а не только `.exe`; на macOS — весь `.app`. Используйте виртуальное окружение и не включайте ключи или местные настройки в архив. Команда сборки может перезаписать предыдущие результаты в `dist/gui` и `build`; проверьте их заранее.

### Windows, PowerShell

```powershell
py -3.12 -m venv .venv-gui
.\.venv-gui\Scripts\python.exe -m pip install 'pyinstaller>=6.15,<7'
.\.venv-gui\Scripts\python.exe -m PyInstaller --onedir --windowed --name JevRouter --distpath dist/gui jev_gui.py
```

Распространяйте целиком `dist/gui/JevRouter`, запуск — `JevRouter.exe`. Пакет не подписан Authenticode; возможны предупреждения SmartScreen.

### macOS, Terminal

На целевой архитектуре используйте Python с рабочим Tkinter (сборка Tcl/Tk зависит от способа установки Python):

```sh
python3.12 -m venv .venv-gui
.venv-gui/bin/python -m pip install 'pyinstaller>=6.15,<7'
.venv-gui/bin/python -m PyInstaller --onedir --windowed --name JevRouter --osx-bundle-identifier ai.jev.router --distpath dist/gui jev_gui.py
```

Результат — `dist/gui/JevRouter.app`. Для архива используйте инструмент, сохраняющий права и символические ссылки, например `ditto -c -k --keepParent`. Сборка без Developer ID и нотариализации может блокироваться Gatekeeper; не отключайте защиту ради проверки.

## Что проверить перед выпуском

- Запуск из пути с пробелами и кириллицей на macOS и Windows без установленного Python; нормальное отображение окна и всех кнопок.
- При открытии окна порт не занят; кнопка запускает worker без второго окна, сообщает об успехе только после подтверждения именно от своего процесса. Занятый порт и отсутствующий ключ дают понятную ошибку, чужой процесс не останавливается.
- Выбор уровней сохраняется и применяется, конфиг OpenCode обновляется с резервной копией, JSONC и чужой `jev` не перезаписываются. Прямой запрос модели не ограничивается чекбоксами.
- При остановке и штатном закрытии завершается только дочерний процесс. При принудительном завершении самого GUI worker может остаться работающим.
- Проверить frozen worker и перенаправление вывода на Windows: поддержка `--windowed` ещё не подтверждена. Локальный `GET /v1/models` с подставным ключом не оплачивается; тестовые обращения к Polza выполнять только с отдельного согласия.
- Перед публичной раздачей подписать и проверить каждый архив; без подписанного издателя пользователи могут видеть системные предупреждения. Роутер слушает только loopback, но локальные процессы могут выполнять запросы за счёт владельца ключа: см. [SECURITY.md](SECURITY.md).
